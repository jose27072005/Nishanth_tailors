# Nishanth Tailors – Tailoring Management System

Nishanth Tailors is a web-based tailoring management system developed to simplify and digitize the daily workflow of my father’s tailoring shop. Instead of maintaining handwritten paper notes and manual bill tracking, this application provides a complete digital workspace for managing customer orders, measurements, billing, and live order tracking.

The system is designed with simplicity, speed, and accessibility in mind, helping reduce workload while improving order management efficiency.

---

## Features

### Admin Authentication
- Secure admin login using Firebase Authentication
- Access control for the main workspace

### Workspace Management
- Create, update, and delete bills
- Add remarks/notes for each order
- Store customer contact details and clothing measurements
- Manage multiple items inside a single bill

### Live Order Tracking
- Left-side live tracking panel for pending orders
- Displays which bill should be completed first
- Track status of each item individually:
  - Shirts
  - Pants
  - Trousers
  - Other tailoring items

### Customer Access
Customers can:
- Track order status using their bill number
- Download digital e-bills
- Make online payments

# Voice-Controlled Billing System

One of the main highlights of this project is the voice-controlled bill creation system, designed to reduce manual typing and speed up workflow inside the tailoring shop.

The application supports both:
- English
- Tamil

### Voice Command Features

## Count Modification Commands
- "Increase shirt count to 3"
- "Set pant count 2"
- "சட்டை எண்ணிக்கை 3 ஆக கூட்டு"

## Price & Amount Commands
- "Enter shirt price 500"
- "Set advance amount 1000"
- "முன்பணத் தொகை 1000 அமை"

## Size Entry Voice Control
- Voice navigation inside size modal
- "Next" / "அடுத்து"
- Automatic size value entry
- "Save" / "சேமி"

## Item Management
- "Add shirt"
- "Select shirt"
- "சட்டை சேர்"

## Complete Workflow Commands
- "Create bill"
- "Shirt size"
- "Advance 500"
- "பில் உருவாக்க"

## Smart Navigation
- Navigate between fields using voice
- Field-specific commands
- Continuous workflow voice interaction
